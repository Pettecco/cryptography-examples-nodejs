# Cryptography Examples in Node.js

This repository contains practical cryptography examples in Node.js, including symmetric and asymmetric encryption, digital signatures, hashing, and JWT authentication.

These examples are based on the course:
[Node.js: Cryptography and JWT Tokens](https://cursos.alura.com.br/course/nodejs-criptografia-tokens-jwt) by Alura.

## Features

- Symmetric encryption
- Asymmetric encryption
- Digital signatures
- Hashing (with and without salt)
- JWT authentication

## Requirements

- Node.js (v14 or higher)
- npm
